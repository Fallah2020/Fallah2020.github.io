# Website publication checklist

1. **Preview locally** using the included rendered HTML preview archive (if provided), or install Quarto and run `quarto preview`.
2. **Review the content** in the `.qmd` pages for factual and publishing accuracy.
3. **Your selected photo is already included.** Review the included public academic CV (PDF) and confirm whether to use your personal email publicly.
4. **Create GitHub repository** named exactly `your-github-username.github.io`.
5. **Upload all source files**, preserving the hidden `.github` directory.
6. **Settings → Pages → Source → GitHub Actions**.
7. **Watch Actions**. Once deployment succeeds, visit `https://your-github-username.github.io/`.

More detail and troubleshooting: [README.md](README.md).
